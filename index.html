Technical & Regulatory Framework

POPIA Compliance & Data Anonymization

Data Minimization: No direct personal identifiers (names, ID numbers, contacts) are stored in persistent storage.

Tokenization: At the API gateway, all sensitive identifiers are replaced with irreversible, randomized tokens. The mapping key stays exclusively with the data provider — re‑identification is mathematically impossible within EthicHawks.

SHA‑256 Cryptographic Hashing: All telemetry logs are hashed to create tamper‑evident audit trails suitable for litigation and regulatory scrutiny.

Data Governance: EthicHawks acts as a POPIA Data Processor, siloing each client’s data in a discrete encrypted environment — no cross‑contamination.

The Wilbur Method™

A proprietary forensic diagnostic framework that maps the structural geometry of an institution using three layers:

  • Clinical Telemetry: Detects suppression anomalies (unreported adverse events).
  • Procurement Geometry: Tracks “velocity bypasses” — abnormal time gaps signalling control circumvention.
  • Human Capital Flux: Correlates staff exodus with risk spikes.

The engine generates immutable forensic evidence bundles (SHA‑256 hashed) ready for parliamentary or SIU submission, turning institutional oversight from retrospective autopsy into predictive governance.
